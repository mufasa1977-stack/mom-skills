# Web-Creativity Prompt Pack

The reusable prompt blocks + techniques that produce cinematic, premium, "$5K-looking" websites from a single Claude Code session. Two proven methods below. Pick the lane, copy the prompt, swap the brackets.

## THE CORE IDEA (why these work)

A premium website is NOT a static page — it is a **scroll-driven cinematic experience**. The scroll "animation" is a **video generated by an AI model, exploded into individual frames**, and those frames are swapped as the user scrolls (frame-by-frame scrubbing, like Apple product pages). This is why 4K/2K source quality matters — you are scrubbing a high-res video, not playing a low-res GIF.

Two build lanes:
- **Lane A — One-prompt, MCP-connected** (fastest, costs credits): Claude has a media-gen MCP attached (Higgsfield) and generates all imagery/video itself from ONE prompt.
- **Lane B — Manual asset pipeline** (more control): generate images → animate to video → merge → hand the final video + a master prompt to Claude Code, which builds the scroll site around it.

Both end the same way: a cinematic scroll site. Lane A is the one to prefer for our stack (we have the Higgsfield MCP).

## LANE A — ONE-PROMPT CINEMATIC SITE (MCP-connected)

**Setup (once):** Higgsfield MCP connected in Claude Code (Connectors → add custom connector → paste Higgsfield remote MCP URL → authenticate; toggle it ON). Effort level **extra** or **max** (extra is the sweet spot). Use a **4K-capable video model** (Seedance 2.0 / "Cance 2.0") + a strong image model (Nano Banana 2/Pro or GPT Image 2). Video model MUST be high-res because the scroll effect scrubs its frames.

### Prompt A1 — Luxury product / brand site (VERBATIM PATTERN)
> Build me an award-winning cinematic 3D scroll website for **[BRAND NAME]**, a fictional **[CATEGORY, e.g. Swiss luxury watch brand]**. Use the Higgsfield MCP to generate all of the images and videos. Generate everything with the **Seedance 2.0** model on the Higgsfield MCP.

When to use: hero product page, watch/jewelry/fragrance, any single-hero luxury item.

### Prompt A2 — Narrative "journey" site (the Abyssal pattern — the most impressive one)
> Build me an award-winning cinematic 3D scroll website for **[BRAND]**, a fictional **[what it does — e.g. deep-sea expedition company that takes 8 civilians per year to the ocean floor aboard a submarine called the Aribbas]**.
>
> Visuals — generate everything with the **Seedance 2.0** model on the Higgsfield MCP. Structure the scroll as a descent/journey through distinct STAGES, each with its own environment, lighting, and a data caption:
> - Stage 1 — [the surface / sunlight zone]
> - Stage 2 — [200m: "99% of sunlight is gone"]
> - Stage 3 — [1,000m: "pressure is 100× the surface"; bioluminescent life makes its own light]
> - Stage 4 — [the ocean floor: "fewer people have stood here than have walked on the moon"]
> - Final — product/spec reveal card: [96-hour life support, 4,000m depth rating, 8 seats, $250,000, departing March 2027].
>
> Give each stage a fixed-position caption on the right that scroll-reveals, subtle scroll-coupled animations (e.g. a jellyfish drift, a light turning on in the dark), and a bold hook line at the very top ("[How deep will you go?]").

When to use: THE premium showpiece format. Any product with a story arc — a descent, an origin, a transformation, a build process. This is what makes a site feel like a $10K brand. Steal the structure (staged descent + data captions + spec-card payoff) for boutique, car ads, PDF landers.

### Prompt A3 — Cinematic personal portfolio (VERBATIM PATTERN)
> Build me an award-winning cinematic 3D scroll personal portfolio website for **[YOUR NAME]**. Study the style of Awwwards Site of the Year. Huge bold typography, cinematic scroll visuals. Generate everything with the **Seedance 2.0** model on the Higgsfield MCP.
>
> [Attach ONE photo of the subject — Claude uses it as the identity reference and generates all the portfolio imagery/video from it.]

When to use: portfolio / personal-brand / "about me" site. One uploaded photo → full cinematic site. High-value freelance deliverable.

### Prompt A4 — Clone-a-reference (fastest path to premium)
> Here is a reference site I like: **[paste URL or describe it]**. Build me something with the same energy and aesthetic for **[my brand / use case]** — same scroll feel, same level of polish, but original copy and visuals. Generate all imagery with the Higgsfield MCP (Seedance 2.0).

When to use: you found a site you love and want its vibe. Pair with the inspiration sources below.

## LANE B — MANUAL ASSET PIPELINE → MASTER PROMPT (max control)

Use when you want to art-direct every frame, or have no media MCP. Pipeline: **generate images (2K) → animate consecutive images into short videos → merge to ONE video → hand video + master prompt to Claude Code → push to GitHub → deploy to Vercel (free).**

### Step 1 — Generate the image set (2K)
Generate ~9 numbered hero images that tell the story in stills (e.g. product, ingredients orbiting, product in context, dawn/dusk/night variants). Model: GPT Image 2 or Nano Banana 2. Ratio 16:9, **2K** (not 1K — you'll scrub these). Name them `image1`…`image9` in narrative order.

### Step 2 — Animate image-to-video (consecutive pairs)
For each transition, use **start frame = imageN, end frame = imageN+1**, with a motion prompt describing the transition (e.g. "herbs falling", "ingredients enter cup", "tea breathing", "hands wrap"). 6s clips, 1080p, 16:9. Model: Seedance 2.0 (or VO 3.1 Light to save credits). Name `v1`…`v5` by beat.

### Step 3 — Merge to ONE video
Merge all clips into a single continuous video (Canva landscape, or ffmpeg for us). Export 1080p. This single file is the scroll-scrub source.

### Step 4 — Master prompt to Claude Code (VERBATIM PATTERN)
> You are building a **luxury scroll-driven narrative website** for **[BRAND]**, a premium **[category]**.
>
> **Core mechanic:** a fixed full-screen `<video>` (or `<canvas>`) that is **scrubbed frame-by-frame by scroll position** — as the user scrolls, the video timeline advances (Apple-style scroll-scrubbing). Video file: `[final.mp4]`.
>
> Include:
> - **Loading screen** (elegant, brand-colored, then fades out)
> - **Fixed header** (minimal, transparent → solid on scroll)
> - **Scroll progress bar**
> - **Text overlays** that fade/slide in at specific scroll points, synced to the video beats: [beat 1 caption], [beat 2 caption], [beat 3 caption]
> - A **product/spec card section** near the end: [3 option cards, or the spec payoff]
> - Footer: [logo, links, CTA]
>
> Aesthetic: cinematic, huge bold typography, generous negative space, muted premium palette, subtle motion only. Build it as a single `index.html`.

### Step 5 — Add card images + fix loop
Drop in card images (e.g. dawn / dusk / night product variants), then:
> Add a gradient fade at the bottom of each card image blending into the card background. Keep all existing card styles exactly the same.

If images don't render: `The pictures in the cards show blank. Check what's wrong and fix them.` (Claude self-corrects.)

### Step 6 — Ship free
`Push all files to this GitHub repo: [URL]` → then Vercel → Add New Project → Import → Deploy. Live URL, $0. (For us: use our own `deploy_snapcal.ps1` / Cloudflare Pages lane instead of Vercel where relevant.)

## TECHNIQUES / AESTHETIC VOCABULARY (name these in prompts — they trigger better output)
- **"cinematic 3D scroll website"** / **"scroll-driven narrative"** — the master keyword; makes Claude reach for frame-scrubbing.
- **Frame-by-frame scroll scrubbing** — video exploded to frames, swapped on scroll (needs 2K/4K source).
- **Staged descent / journey structure** — distinct scroll stages, each = new environment + lighting + a DATA caption (the Abyssal pattern). Highest-impact single technique.
- **Data captions as drama** — hard numbers as scroll reveals ("99% of sunlight gone", "pressure is 100× the surface", "fewer people than have walked on the moon"). Numbers make it feel authoritative and premium.
- **Huge bold typography** + generous negative space.
- **Fixed side-captions** that scroll-reveal on the right.
- **Micro-motion touches** coupled to scroll (a jellyfish drift, a light turning on) — restraint, not everything moving.
- **Spec-card payoff** at the end (price, capacity, date) — converts the mood into a product.
- **Loading screen + scroll progress bar + transparent→solid header** — the polish trio that reads "expensive".
- **One-hero focus** — a single fictional brand/product, fully committed, beats a generic multi-product page.

## MOTION-CLONE RE-SKIN + KINETIC TYPE (mined 2026-07-03, VBvxHIkvjeo + IeR5ZMKssSc — Viktor Oddy lane)
**Motion-clone re-skin (the $5K-website engine):** take a proven hero video whose MOTION you love →
2-image edit swaps the subject ("replace the flower in image 1 with image 2") → feed Seedance 2 BOTH
the reference VIDEO and the new still → identical camera move/timing with the new subject. LAW: output
duration must MATCH the reference exactly. One killer scroll-hero becomes a per-client template
(boutique garments, dealership REAL-photo cars — pairs with hyperreal-use-real-asset).
**Explode/reassemble scrub:** start still → instruction-edit an "exploded state" END frame (additive
language: "keep the [subject] intact and centered, ADD flying debris frozen mid-air around it" — naive
'explosion' prompts rip the subject) → start/end-conditioned i2v → scrub. Reassembly = scrubbing back,
or palindrome map `frame=round((1-Math.abs(2*p-1))*(N-1))` to explode-and-reassemble in ONE pass.
High-motion seams need ~120-170 frames (72 strobes). Camera LOCKED during the blast.
**Kinetic type devices:** char-by-char headline exit (fall+squish+fade, staggered, scroll-tied);
3D text drum (paragraph on a virtual cylinder, rotateX/translateZ from a focus line, blur+opacity
falloff — great for classified-document excerpts); blur-to-sharp staggered entrances; fluid
full-width uppercase display headline; "design is 50% fonts" — one distinctive display font.
**Lighter scrub alt:** muted <video>.currentTime per rAF from scroll (1080p not 4K; needs
keyframe-dense encoding) — frame-sequence canvas remains the buttery default.
**Screenshot-to-recreate:** see an effect anywhere → screenshot → "recreate this exact thing."
**Distribution flywheel:** square screen-capture of the finished scroll site → post to X tagging the
tools/creators — repost reach is free marketing. Bar: don't post 4/10 work.

## FUI / SCREEN-GRAPHICS PACKAGE (Tariq 2026-07-04 — the scanner/tracker interface family)
The industry term for movie UI overlays: **FUI (Fictional User Interface)**, delivered as a
"screen-graphics package" (Territory Studio: MI + BR2049; Perception: Iron Man HUD). OUR package:
- **COLOR LAW (corrected by Tariq same day — do NOT hardcode a palette): color is scene-appropriate,
  chosen by what the in-world device would truly display.** A jet HUD reads green/amber because real
  HUDs do; a subway face-pay screen, a police plate-reader, a hospital monitor each carry their own
  palette. The earlier "always orange/green" note was a transcription error — DEPRECATED.
- THE ELEMENT FAMILY (all one grammar — a machine perceiving the world):
  · missile/target LOCK (Top Gun): corner brackets that track + tighten on the subject, tone-ramp,
    "LOCKED" state change
  · facial recognition (MI / China subway face-pay): scanline sweep + landmark dots + match/no-match
    verdict card, walk-through payment confirmation
  · pedestrian tracking boxes (street surveillance): a box following each moving subject with a
    small data tag (id/attribute), multiple simultaneous
  · license-plate reader (ALPR): plate zoom-crop inset + OCR characters resolving + database row
  · generic diagnostics: dealership scanner on a real car, fabric/garment scanner, radar scopes
- Build kit: corner brackets (4 L-shapes), scanline sweep, mono readouts (10-11px, letter-spaced,
  staggered), inset zoom-crops, landmark dots — all scroll-drivable; glow via text-shadow.
- STORY LAW: FUI must SAY something ("PROFILE SEARCH: NO MATCH" = thesis as UI). A scan that returns
  the story beat beats decoration every time. Diegetic: the interface belongs to something in-world.
- Screen-life format note (War of the Worlds '25, Ice Cube): an entire story told through
  surveillance/screens/feeds = an ultra-cheap FF episode format (all FUI, minimal renders).

## SCI-FI LOOK-PACK (mined 2026-07-04, mOJla68Qers — 27-film visual-craft catalog as named presets)
Each preset = palette + scale rule + texture + signature move. Zero render cost — prompt/grade grammar.
- **MONOLITH (Arrival/Dune):** massive smooth shape hanging SILENT; humans as specks; muted palette;
  menace = stillness + negative space, never motion. THE ceiling for UFO/FF docudrama shots.
- **TWO-PALETTE CONTRAST LAW:** every world = two palettes in tension (neon rain vs golden minimalism,
  junk-tech below vs gleaming utopia above). One palette = flat world.
- **IMPOSSIBLE-COLOR (Annihilation/Color Out of Space):** the unrepresentable = ONE hypersaturated
  signature color/shimmer that gradually grades the whole third act. Port: scroll-position-driven
  grade shift for a page's reveal section.
- **TACTILE LEXICON (why AI output reads fake — too clean):** prompt weight, rust, gears, grime,
  fabric wear, miniature-texture; practical-puppet heaviness. Drop into every photoreal prompt.
- **LIGHT AS ANTAGONIST (Sunshine/Oblivion):** a light source with will — godlike golden sun,
  clinical bright apocalypse; beauty as menace.
- **WORLD-INTRO ONER:** one continuous tracking shot teaches the whole space = a pinned scroll-scrub
  sequence (Tomorrowland pin-transport is literally a scroll-cinema transition).
- **CITY-SCALE FUI (Ghost in the Shell):** building-height holograms swimming BETWEEN structures;
  alien logograms (Arrival) as language-FUI; hyperspectral-goggle overlay = "what the sensors saw" beat.
- **TUNING-MORPH (Dark City):** architecture-scale morphs — buildings stretch/spiral; our palindrome
  aimed at BUILDINGS, morph laws apply at city scale.
- **RETROFUTURE COMMIT (Sky Captain/Tomorrowland):** pick one era's vision of the future, commit 100%.
